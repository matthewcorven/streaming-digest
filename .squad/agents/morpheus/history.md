- 2026-07-25: Synthesized the three merged prototypes (11.3a/11.3b vector, 7.4 screenshots) into `docs/verification/prototype-synthesis-11.3a-11.3b-7.4.md`. Learnings: (1) **PROVEN-mechanism ≠ PROVEN-value** — 11.3b validated §6's ranking plumbing but the flat synthetic recall surface means no weight/threshold *value* is validated; conflating these is how a team ships untuned defaults believing they were tested. Every review must name which kind of proof a verdict is. (2) **A verification report is evidence, not a decision record** — 11.3a "refined" the open §3.22 index choice to HNSW but filed no ADR; I overturned that process call (ADR-0016 required) because an implementer reads DATA_MODEL + the ADR index, not a prototype's findings section, and §3.22 explicitly left the choice open. The ADR bar (hard-to-reverse + surprising + real trade-off) applies to *closing* an open decision, not just *overturning* an existing one. (3) **Latency findings need the right denominator** — 11.3b's 447 ms hybrid number was measured on a 12k-doc synthetic corpus dominated by per-query tsvector construction; it is an implementation finding (→ materialized tsvector hard-requirement for Task 12.3), not a design threat, and must never be quoted as the design's latency. (4) **INCONCLUSIVE-by-construction is an honest answer, not a failure** — the synthetic embedder has no semantic invariance, so paraphrase recall and ADR-0012's threshold value are correctly deferred; the synthesis' job is to name exactly where each deferred question lands (12.7 harness, new calibration issue, 12.8 re-measure) so it cannot silently vanish. (5) **A disproven task framing is a prototype success** — 7.4 showed "ffmpeg vs yt-dlp" was a false two-horse race (yt-dlp delegates to ffmpeg); catching that in a cheap spike before Task 7.5 is the prototype-early policy working. (6) **Spike code stays on main as primary-source evidence**, excluded from the slnx; `spikes/README.md` now records the standing convention so a second spike (PR #98) doesn't read as an accident.
