User directive from Matthew Corven on 2026-07-26T09:32:55.359-04:00: Always delegate implementation work to subagents using model `mai-code-1-flash-picker`. Before starting implementation, the subagent must create or switch to an issue branch and open a draft PR linked to the issue, then investigate surrounding existing implementations to understand precedent, architecture, design, and structural patterns. When the subagent believes the work is complete, it must ask the coordinator to confirm the implementation is fully functional and aligned with founding documents and issue directives. Only after coordinator affirmation may the subagent mark the PR ready for review.
