# Test fixtures

This directory contains synthetic or derived test fixtures for the Streaming Digest test suite.

Provenance and licensing notes:
- The fixtures are intentionally small and synthetic; they are not derived from copyrighted media assets.
- JSON, HTML, text, and metadata fixtures are authored for test behavior and compatibility only.
- Binary placeholder files (`.wav`, `.mp4`) are minimal stand-ins for content processing tests and are not intended for redistribution.
