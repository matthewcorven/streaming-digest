## Run 2 — 2026-07-25

### Outcome

Validated the containerized worker image with real Docker-provided ffmpeg and confirmed the WebP codec is available and can generate an output file from the sample media fixture.

### Environment

- Host OS / arch: macOS arm64 (Apple Silicon)
- Docker: 29.5.3
- Container image: `streaming-digest-worker-test`

### Verification commands

```bash
docker build -t streaming-digest-worker-test -f src/StreamingDigest.Worker/Dockerfile .
docker run --rm --entrypoint ffmpeg streaming-digest-worker-test -encoders 2>/dev/null | grep -i webp
docker run --rm -v "$PWD/tests/Fixtures/video/test-screenshot.mp4:/tmp/input.mp4:ro" -v "/tmp/streaming-digest-docker-validate:/tmp/out" --entrypoint ffmpeg streaming-digest-worker-test -y -loglevel error -ss 1 -i /tmp/input.mp4 -frames:v 1 -c:v libwebp -quality 80 /tmp/out/screenshot.webp
```

### Result

- `libwebp` encoder present in container ffmpeg build: Yes
- Generated output: `/tmp/streaming-digest-docker-validate/screenshot.webp`
- File type: WebP image (RIFF/Web/P image)
